## Sobre o Projeto

A **Flix API** é uma API RESTful completa, construída com **Django** e **Django REST Framework**. O objetivo deste projeto é fornecer todos os endpoints necessários para que uma aplicação front-end (seja web ou mobile) possa gerenciar usuários, catalogar filmes e permitir que os usuários controlem o que já assistiram, o que querem assistir e seus filmes favoritos.

## Funcionalidades Principais

- **Autenticação Completa:** Sistema de registro e login de usuários com gerenciamento de tokens.
- **Gerenciamento de Filmes:** Operações CRUD (Criar, Ler, Atualizar, Deletar) para filmes.
- **Favoritos e Lista de Desejos:** Permite que usuários autenticados adicionem e removam filmes de suas listas pessoais.
- **Busca e Filtragem:** Endpoints otimizados para buscar e filtrar filmes por título ou outros critérios.
- **Documentação Clara:** A API foi desenvolvida para ser intuitiva e fácil de consumir.
